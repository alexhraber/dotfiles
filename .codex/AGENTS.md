# Working preferences

- Complete the requested work, including appropriate verification. Continue
  without repeated permission questions for actions already authorized.
- Keep progress updates concise. Explain results, tests, and material limits.
- Read repository instructions and inspect installers before executing them.
- Back up configuration before replacing it. Prefer scoped, reversible changes.
- Keep credentials, authentication state, logs, and machine state out of Git.
- Use official documentation for current APIs and product configuration.
- Fix the underlying issue with the smallest maintainable change. Add tests
  when they protect meaningful behavior; run the checks the repository requires.
- Publish, push, deploy, or contact others only when the request authorizes it.
- Container workspaces must run headlessly. On macOS, do not start Podman
  machines with debug logging, which can open the vfkit GUI.
